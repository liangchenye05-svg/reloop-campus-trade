# CampusTrade V1 验收范围

面向同一校园内的闲置物品交易。用户可以同时担任买家和卖家。管理员权限用于下架违规商品，已有订单保留原商品快照。交付通过线下见面完成，系统记录模拟支付与买家收货确认。

| 模块 | 验收行为 |
| --- | --- |
| 账户 | 注册、登录、查看本人资料；JWT 缺失、无效或过期时返回 401；越权返回 403 或隐藏资源返回 404 |
| 商品 | 卖家发布、编辑、上架和下架；游客查看在售详情并按关键字和分类分页；管理页显示本人全部商品 |
| 购物车 | 增减数量和移除条目；结算时重新校验库存、状态、归属和价格；禁止购买自己的商品 |
| 订单 | 一次结算选中条目；保存商品名称、单价、数量和卖家快照；请求重放返回同一订单 |
| 支付 | 模拟支付仅允许未超时的待支付订单，重复支付幂等；已支付订单由买家确认完成 |
| 取消与超时 | 仅待支付订单允许取消或超时关闭；库存只恢复一次；卖家修改库存时仍计入未支付预留 |
| 工程 | MySQL 实测事务与库存；Redis 对比实测；RocketMQ 重试与延迟实测；服务注册、调用、日志和容器实测 |

## 交易流程

卖家发布 → 买家选择商品 → 加入购物车 → 结算并预留库存 → 模拟支付 → 线下交付 → 买家确认完成。未支付订单可由买家取消，或到期后自动关闭。取消与超时后恢复库存。

暂不提供线上收款、物流、退款和仲裁。平台为单校部署。公开商品图片由发布人提供 http(s) URL。
