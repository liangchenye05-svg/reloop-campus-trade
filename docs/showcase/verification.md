# ReLoop 验收与指标口径

## 本轮展示验收

| 验证 | 实际结果 |
| --- | --- |
| 隔离 | reloop-showcase 使用独立卷和网络，原 campus-trade 11 个容器 ID 保持一致 |
| API 与图像 | 10 件合成目录记录通过现有 API 发布，10/10 图片成功，类别、价格、状态与种子一致 |

## 历史指标

- 12 路争抢最后一件，1 成功、11 冲突。12 次同键产生一笔订单。
- Redis 在 30,020 件在售商品样本上为 3,006.26 请求/秒、P95 4.76 ms，MySQL 直读为 806.23 请求/秒、P95 12.21 ms。每轮 1,600 请求、8 个并发，三轮取中位数。
- 原工程记录涵盖 Broker 停复后的 Outbox 投递、消息去重和超时返库，以及 Nacos 注册、Feign 与 traceId、故障 503。

这些是历史固定条件结果。可以在隔离环境复跑 [交易验证](../../tests/api/exercise.py)、[缓存压测](../../tests/performance/cache_comparison.py) 与 [消息可靠性](../../tests/api/mq_retry.py)。 [展示复现](demo-guide.md)
